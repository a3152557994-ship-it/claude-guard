Claude Code 接入 AWS Bedrock 与 Google Vertex AI 零封号配置教程 (含 settings.json)

💡 核心结论（40秒速读）：要让 Claude Code 100% 永不封号，最彻底的工程方案是绕开 Anthropic 个人消费者账号（Consumer Pro/Max）风控，直接在 ~/.claude/settings.json 中设置 CLAUDE_CODE_USE_BEDROCK=1（走 AWS Bedrock）或 CLAUDE_CODE_USE_VERTEX=1（走 Google Cloud Vertex AI），同时配置 DISABLE_TELEMETRY=1 关闭非必要遥测上报。

一、 为什么企业级 AWS Bedrock / Google Vertex AI 绝对不会封个人号？

Anthropic 官方个人网页端与 Pro/Max 订阅采用极其严苛的地区与设备指纹风控；而 AWS Bedrock 与 Google Cloud Vertex AI 属于云厂商托管的企业级商业 API：

  • 零封号风控：计费与鉴权完全走你自己的 AWS IAM 或 Google Cloud 结算账号，不受 Anthropic 个人号 IP 跳变风控限制；
  • 按量透明计费 + 可白嫖云赠金：支持 Prompt Caching（提示词缓存省 90% 输入成本），且 Google Vertex AI 可直接消耗 Google Cloud 新户 $300 赠金或开发者计划每月赠金。

二、 标准 ~/.claude/settings.json 配置模板（直接复制可用）

方案 A：AWS Bedrock 零封号 + 防遥测加固配置

{
  "env": {
    "DISABLE_TELEMETRY": "1",
    "DISABLE_ERROR_REPORTING": "1",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_USE_BEDROCK": "1",
    "AWS_REGION": "us-east-1",
    "ANTHROPIC_MODEL": "us.anthropic.claude-sonnet-4-20250514-v1:0"
  }
}

方案 B：Google Cloud Vertex AI 零封号配置

{
  "env": {
    "DISABLE_TELEMETRY": "1",
    "DISABLE_ERROR_REPORTING": "1",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_USE_VERTEX": "1",
    "CLOUD_ML_REGION": "us-east5",
    "ANTHROPIC_VERTEX_PROJECT_ID": "your-gcp-project-id"
  }
}
